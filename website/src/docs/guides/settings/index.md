# Settings

Open the settings from <nav to="settings">. The search icon on top lets you find any option by name, so you don't have to remember which section it is in.

Every settings screen has a `Reset` option at the bottom that resets only the preferences of that screen to their defaults.

| Section | What's in it |
| --- | --- |
| [General](/docs/guides/settings/general) | Language, theme, accents, home screen, navigation bar, YouTube data fetching, search, swipe gestures, share menu. |
| [Folders](/docs/guides/settings/folders) | Where files are saved, cache, filename templates, subfolders, temporary files. |
| [Downloads](/docs/guides/settings/downloads) | How downloads run: duplicates, network, speed, concurrency, retries, scheduling. |
| [Processing](/docs/guides/settings/processing) | What the app does to the media: audio, video, subtitles, thumbnails, SponsorBlock, metadata, formats. |
| [Updating](/docs/guides/settings/updating) | yt-dlp, the app, packages, format ordering. |
| [Advanced](/docs/guides/settings/advanced/) | YouTube player clients and PO tokens, format sorting, extra commands for data fetching, and other low level options. |

At the bottom of the main settings screen you also find:

- **Backup / Restore / Automatic backup**: see [Backups](/docs/guides/backups)
- **About**: package name, Discord, Telegram, translations, privacy policy, license and source code. The package name (`com.deniscerri.ytdl`) is what other apps use to connect to YTDLnis.
