# Downloads

The **Downloads** tab is your download history. Every finished download is listed here, unless it was downloaded in [incognito mode](/docs/guides/settings/downloads#incognito).

## Browsing

- Use the search icon to search through your history by title or author.
- Switch between **list** and **grid** layout with the layout chip.
- Use the filter chips to show only **audio**, **video** or **command** downloads.
- Use the sort chip to sort by **date added**, **title**, **author** or **file size**, ascending or descending.
- Open the `Filters` menu for more filters:
  - **Status**: show items whose file is still present (`Not deleted`), items whose file was removed from the device (`Deleted`), or `All`
  - **Website**: show items from a specific website

Thumbnails can be hidden to save space with `Hide thumbnails` in <nav to="general">.

## Item actions

- **Tap** an item to see its details: title, author, format, file size, path, URL, and the actions below.
- The **quick action button** on each card either **shares** or **opens** the file. You can choose which in <nav to="general"> with `Quick Action Button`.
- **Redownload** an item. If you long press the redownload button in the details sheet, the [Download Card](/docs/guides/download-card) opens so you can change the configuration.
- **Open** the file in your media player, **share** it, or copy its **URL**.
- **Delete** an item. You will be asked if you also want to delete the file from the device.

### Swipe gestures

If enabled in <nav to="general">, you can swipe items to act on them quickly. Usually swipe left to redownload and swipe right to delete.

## Selecting multiple items

Press and hold an item to start selecting. From the context bar you can:

- `Select all`, `Invert selected` or `Select items between`
- `Share` the files
- `Redownload` them
- `Copy URLs`
- Delete them, optionally including the files

## History cleanup

The overflow menu has:

| Action | What it does |
| --- | --- |
| **Remove deleted** | Removes entries whose files no longer exist on the device. |
| **Remove duplicates** | Removes repeated entries of the same download. |
| **Remove all** | Clears the whole history. It also asks whether to delete the files. |
| **Copy URLs** | Copies the links of all items shown. |

## Incognito

Items downloaded in incognito mode never show up here, and no log is kept of them. You can turn incognito on for every download in <nav to="downloads"> or only for a single item in the [Download Card](/docs/guides/download-card).
