# How to use Extra Commands

Extra Commands help advanced users to modify a download item by introducing raw yt-dlp commands that are appended in the end of the one that is generated by the app itself through the user interface. Although the GUI covers most of the functionality, sometimes you need to get specific and extra commands allow you to do this without getting full Terminal Mode.

In the Extra Commands screen you have access to your [command templates](/docs/guides/command-templates) and shortcuts to build the command.

## Where to find them

- Per download: `Add Extra Commands` in the Adjust section of the audio or video tab in the [Download Card](/docs/guides/download-card).
- For every download: when creating a [command template](/docs/guides/command-templates), mark it as the **extra command**. It will be appended to every audio and video download.

You can turn off the use of extra commands at any time with `Add extra commands` in <nav to="processing">.

## Examples

| Goal | Extra command |
| --- | --- |
| Limit the download to videos shorter than 10 minutes | `--match-filters "duration < 600"` |
| Don't continue after a failed item in a playlist | `--abort-on-error` |
| Write the description and info json | `--write-description --write-info-json` |
| Use a specific extractor argument | `--extractor-args "youtube:player_client=web"` |

::: tip Note
Extra commands are appended at the end, so they can override the options set by the interface. Be careful with options that change the output path or the format, as they can conflict with what the app expects.
:::
